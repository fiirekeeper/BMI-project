
# BMI Calculator

A simple **Body Mass Index (BMI) Calculator** developed using JavaScript.

The project allows users to calculate their BMI by entering their weight and height through interactive prompts displayed on the screen. The result is then displayed in the browser console.

## Features

- Calculates the user's Body Mass Index (BMI).
- Collects user data through interactive prompts.
- Displays the calculation result in the browser console.
- Uses a simple and straightforward JavaScript implementation.

## Technologies Used

- JavaScript

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/your-repository.git
   ```

2. Open the project in your preferred code editor.

3. Run the `index.html` file in your browser.

4. Enter your weight and height when prompted.

5. Open the browser's developer console to see the BMI calculation result.

## BMI Formula

The BMI is calculated using the following formula:

```javascript
BMI = weight / (height * height);
```

Where:
- `weight` is measured in kilograms (kg).
- `height` is measured in meters (m).
